Drücke Strg + V, ziehe ein Bild hierher oder wähle eine Datei.

Dein Bild wird nur in diesem Browser verarbeitet und nie an einen Server übertragen.

Hilfe & Datenschutz

Datenschutz

  • Screenshots werden ausschließlich lokal in deinem Browser verarbeitet. Es findet kein Upload statt.
  • Der Server liefert nur die Programmdateien aus. Er speichert keine Bilder und protokolliert keine Zugriffe.
  • Es werden keine Cookies, kein Local Storage und keine externen Dienste (CDNs, Schriftarten, Tracking) verwendet.
  • Eine Content-Security-Policy verbietet der Seite technisch jede Netzwerkverbindung (connect-src 'none').
  • Mit dem Schließen des Tabs oder „Bild verwerfen“ ist das Bild aus dem Arbeitsspeicher entfernt.

Tipp: Für Passwörter, Tokens oder personenbezogene Daten ist Schwärzen am sichersten. Verpixelter oder weichgezeichneter Text lässt sich unter Umständen rekonstruieren.
